💤 LazyVim Dotfiles
My personal Neovim configuration based on [LazyVim](https://github.com/LazyVim/LazyVim).

## Features

- **LazyVim** - Fast and modern Neovim configuration framework
- **Database Tools** - Dadbod, DBUI, and PostgreSQL support
- **Python Development** - DAP debugging and virtual environment support
- **UI** - Tokyo Night theme with Lualine statusline
- **Code Quality** - Conform for formatting, LSP for language support


## Structure

- `nvim/lua/config/` - Core configuration (keymaps, options, lazy setup)
- `nvim/lua/plugins/` - Plugin configurations
- `nvim/lua/db/` - Database connection settings (gitignored)
